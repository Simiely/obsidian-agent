# 01 - 功能说明

> 本文档定义程序的完整功能清单与用户流程。带 ✅ 为 MVP 必做，带 ⏳ 为规划中/增强项。

---

## 1. 功能总览

| 编号 | 功能域 | 功能点 | 优先级 | 说明 |
|---|---|---|---|---|
| F01 | 浏览 | Vault 目录树展示 | ✅ | 按目录层级展示全部 md 文档，支持展开/折叠、按文件名排序 |
| F02 | 浏览 | 文件信息面板 | ✅ | 显示路径、大小、修改时间、frontmatter 标签/别名 |
| F03 | 阅读 | Markdown 渲染 | ✅ | 支持 Obsidian 语法：frontmatter、`[[]]` wikilink、callout、`==高亮==`、Mermaid、LaTeX（基于 Quartz 官方 obsidian 语法插件） |
| F04 | 阅读 | 阅读/编辑双模式切换 | ✅ | 阅读视图（渲染后）+ 编辑视图（原始文本）即时切换 |
| F05 | 编辑 | Markdown 编辑 | ✅ | 浏览器内编辑并保存，**保留原始语法与格式** |
| F06 | 编辑 | 保存前 diff 预览 | ⏳ | 显示改动差异，防误操作 |
| F07 | 编辑 | 自动版本备份 | ✅ | 每次 Agent 写入前自动备份到 `data/backups/` |
| F08 | 检索 | 全文索引 | ✅ | 所有 md 文档逐字索引（含 frontmatter 与正文），首次全量、之后增量 |
| F09 | 检索 | 全文搜索 | ✅ | 中文分词、关键词高亮、结果分页、命中位置跳转 |
| F10 | 检索 | 高级搜索语法 | ⏳ | `path:`、`tag:`、`created:` 等过滤（Obsidian 搜索语法子集） |
| F11 | 检索 | 检索结果定位 | ✅ | 点击结果直接打开文档并滚动到命中位置 |
| F12 | Agent | 自然语言问答 | ✅ | "总结这篇文档"、"XXX 是什么" |
| F13 | Agent | 自然语言检索 | ✅ | "找出所有提到 Docker 部署的笔记" |
| F14 | Agent | 自然语言编辑 | ✅ | "给这篇文档加一段"、"把标题改成 XX"（写前备份 + 结果 diff 展示） |
| F15 | Agent | 批量操作 | ⏳ | "把这 3 篇笔记的标签统一加上 #todo" |
| F16 | Agent | 对话上下文 | ⏳ | 记住当前打开的文档与最近操作，支持多轮 |
| F17 | 系统 | 索引状态页 | ✅ | 显示索引进度、文档总数、最后更新时间，可手动触发重建 |
| F18 | 系统 | 文件变更监听 | ✅ | vault 内文件被 Obsidian 修改后自动增量重索引 |
| F19 | 系统 | 忽略规则 | ✅ | 默认忽略 `.obsidian/`、`.trash/`、`.git/` 等，可配置 |
| F20 | 系统 | 多用户认证 | ⏳ | 简单访问口令（局域网部署时防随手访问） |
| F21 | 编辑 | 原版 Obsidian 编辑体验（Ignis 集成） | ⏳ | 可选：并行部署 Ignis 指向同一 vault，获得完整插件生态编辑体验；本项目自动增量索引其变更 |
| F22 | 备份 | 整库快照备份 | ✅ | 手动/定时创建 vault 全量快照（硬链接增量、空间高效），快照含完整性校验 |
| F23 | 备份 | 定时自动备份 | ✅ | 可配置 cron（默认每日 02:00），后台静默执行，失败告警 |
| F24 | 备份 | 单文件版本恢复 | ✅ | 每个文件的历史版本时间线（含 Agent 写前备份），一键恢复任意版本 |
| F25 | 备份 | 整库恢复 | ⏳ | 从指定快照整体还原（危险操作：恢复前强制再快照 + 双重确认） |
| F26 | 备份 | 保留策略与自动清理 | ✅ | 按"日/周/月"保留规则清理旧快照，磁盘空间可控 |

## 2. 非目标（明确不做）

- 不做 Obsidian 插件的完整兼容（默认自研轻量视图，覆盖核心语法；需要完整插件体验可启用 F21 Ignis 集成）
- 不做多 vault 同时管理（MVP 单 vault，可通过多实例扩展）
- 不做笔记同步/迁移（那是 Obsidian Sync / 网盘的事）
- 不做复杂权限系统（单用户自托管工具，非企业级协作平台）

## 3. 用户流程示例

### 3.1 浏览 → 阅读 → 编辑

```
打开首页 → 左侧目录树点开「Projects/Obsidian 插件」→
右侧阅读视图渲染出文档 → 点击「编辑」切到原始文本 → 修改保存 → 切换回阅读视图确认
```

### 3.2 全文检索定位

```
顶部搜索框输入「中文分词」→ 下拉出现候选 → 回车 → 结果页展示命中文档列表（带高亮摘要）→
点击某条 → 打开文档并自动滚动到第一个命中位置
```

### 3.3 AI Agent 操作

```
对话面板输入：「在今天的日记里追加：- [ ] 复习 Docker 网络模式」→
Agent 定位日记 → 展示将要写入的内容（diff）→ 确认 → 写入成功（备份已生成）→
Agent 回复：「已追加到 2026-07-31.md，备份位于 data/backups/xxx.md.bak」
```

## 4. 技术能力约束

| 项 | 约束 |
|---|---|
| 文档格式 | Markdown（`.md`），UTF-8（兼容带 BOM / GBK 历史文件读取，写入统一 UTF-8） |
| 文件大小 | 单文件 < 5MB（超过则索引正文、禁止 Agent 整体重写） |
| 库规模 | 10 万文件以内索引性能可接受（增量索引秒级） |
| 并发编辑 | 与 Obsidian 桌面端同时打开同一 vault 是支持的（原子写入 + 监听重索引） |
