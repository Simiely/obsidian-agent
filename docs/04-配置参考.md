# 04 - 配置参考

> 全部配置项说明。配置方式：环境变量（Docker 场景写入 `.env`），本地开发也可直接 export。

---

## 1. 环境变量总表

### 1.1 核心

| 变量 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `VAULT_PATH` | ✅ | - | 宿主机 Obsidian 库绝对路径，如 `D:/MyVault` |
| `PORT` | - | `8080` | Web 服务端口（容器内固定 8080，改这个映射宿主机端口） |
| `DATA_DIR` | - | `/data` | 索引库与备份目录（容器内，compose 已挂 volume） |
| `INDEX_BACKEND` | - | `fts5` | 索引实现：`fts5`（默认，零依赖）/ `meili`（需 meili 容器） |
| `MEILI_URL` | - | `http://meilisearch:7700` | 仅 `INDEX_BACKEND=meili` 时需要 |
| `MEILI_MASTER_KEY` | - | 空 | 同上 |

### 1.2 LLM（Agent 必配）

| 变量 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `LLM_PROVIDER` | ✅* | `deepseek` | `deepseek` / `openai` / `kimiapi` / `ollama` / `custom` |
| `LLM_API_KEY` | * | 空 | 云服务必填；`ollama` 可不填 |
| `LLM_BASE_URL` | - | 按 provider | 自定义网关地址（如 `https://api.deepseek.com/v1`） |
| `LLM_MODEL` | - | 按 provider | 模型名，如 `deepseek-chat` / `gpt-4o-mini` / `qwen-plus` |
| `LLM_MAX_TOKENS` | - | `4096` | 单次响应上限 |
| `LLM_TEMPERATURE` | - | `0.2` | 编辑/检索任务建议低温，减少乱改 |
| `OLLAMA_HOST` | - | `http://host.docker.internal:11434` | Ollama 服务地址（Docker Desktop 可直连宿主机） |

> `*`：不启用 Agent 功能（纯浏览+搜索）时可不配 LLM；配置 `LLM_PROVIDER` 后必须保证 key/URL 可用。

### 1.3 Vault 行为

| 变量 | 默认值 | 说明 |
|---|---|---|
| `IGNORE_DIRS` | `.obsidian,.trash,.git,node_modules,.stfolder` | 逗号分隔，索引与树展示均忽略 |
| `IGNORE_FILES` | 空 | 逗号分隔的忽略文件名 |
| `MAX_FILE_BYTES` | `5242880` (5MB) | 超过此大小的文件：索引正文、禁止 Agent 重写 |
| `WATCH_ENABLED` | `true` | 是否监听文件变更自动增量索引 |
| `WATCH_DEBOUNCE_SECONDS` | `2` | 变更事件合并窗口 |

### 1.4 安全

| 变量 | 默认值 | 说明 |
|---|---|---|
| `AUTH_TOKEN` | 空 | 非空时启用简单口令认证（请求头 `X-Auth-Token`），局域网部署建议开启 |
| `DISALLOWED_WRITE_DIRS` | `.obsidian,.trash,.git` | Agent 禁写目录（黑名单） |

### 1.5 备份（快照）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `BACKUP_ENABLED` | `true` | 总开关：写前单文件备份 + 整库快照备份 |
| `BACKUP_DIR` | `{DATA_DIR}/backups` | 备份根目录（**必须位于 vault 之外**，已在忽略规则中） |
| `BACKUP_SCHEDULE` | `0 2 * * *` | 定时快照 cron（默认每日 02:00；空 = 不自动，仅手动触发） |
| `BACKUP_RETENTION` | `7d,4w,3m` | 保留策略：最近 7 天每日 + 4 周每周 + 3 月每月，超限自动清理 |
| `BACKUP_MAX_BYTES` | `10485760` (10MB) | 快照跳过超大附件（防止快照膨胀） |
| `BACKUP_VERIFY` | `true` | 快照完成后抽样校验（文件数 + 抽样 checksum） |

### 1.6 索引性能

| 变量 | 默认值 | 说明 |
|---|---|---|
| `INDEX_BATCH_SIZE` | `200` | 全量索引每批文件数（越大越快、越吃内存） |
| `INDEX_WORKERS` | `2` | 并行解析线程数 |
| `JIEBA_USERDICT` | 空 | jieba 自定义词典路径（如 `./data/userdict.txt`，每行一个词，含词频/词性可选），用于提升领域术语分词命中率 |

## 2. 配置示例

```bash
# .env.example
# ---- 核心 ----
VAULT_PATH=D:/MyVault
PORT=8080
DATA_DIR=/data
INDEX_BACKEND=fts5

# ---- LLM（示例：DeepSeek）----
LLM_PROVIDER=deepseek
LLM_API_KEY=sk-xxxxxxxx
LLM_MODEL=deepseek-chat

# ---- 或：本地 Ollama ----
# LLM_PROVIDER=ollama
# LLM_MODEL=qwen2.5:7b
# OLLAMA_HOST=http://host.docker.internal:11434

# ---- Vault 行为 ----
IGNORE_DIRS=.obsidian,.trash,.git,node_modules,.stfolder
WATCH_ENABLED=true
WATCH_DEBOUNCE_SECONDS=2

# ---- 安全 ----
AUTH_TOKEN=
DISALLOWED_WRITE_DIRS=.obsidian,.trash,.git

# ---- 备份 ----
BACKUP_ENABLED=true
BACKUP_SCHEDULE=0 2 * * *
BACKUP_RETENTION=7d,4w,3m
BACKUP_VERIFY=true
```

## 3. 权限（PUID/PGID）

容器默认以非 root 用户运行。若宿主机 vault 目录权限导致容器内无法写入：

```yaml
# docker-compose.yml 中
services:
  app:
    environment:
      PUID: 1000      # 宿主机用户 uid（Linux: id -u）
      PGID: 1000      # 宿主机用户 gid（Linux: id -g）
```

Windows/macOS（Docker Desktop 文件共享）一般无需设置；Linux 部署务必匹配宿主 uid/gid。

## 4. 验证配置

```bash
# 容器内打印生效配置（不含密钥明文，key 显示为掩码）
docker compose exec app python -m app.config --check
```
