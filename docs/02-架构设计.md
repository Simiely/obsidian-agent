# 02 - 架构设计

> 本文档说明程序的分层架构、模块职责、技术选型与数据流。**改代码前必读**。

---

## 1. 架构总览

```
┌─────────────────────────────────────────────────────────────┐
│                       用户浏览器 (Web UI)                     │
│   目录树 │ 阅读视图 │ 编辑视图 │ 搜索页 │ Agent 对话面板       │
└──────────────────────────┬──────────────────────────────────┘
                           │ HTTP (REST + SSE)
┌──────────────────────────▼──────────────────────────────────┐
│                     API 层  (FastAPI)                        │
│   /api/vault   /api/search   /api/index   /api/agent         │
│   统一异常处理 · 路径穿越防护 · 请求校验                      │
└──┬──────────────┬──────────────────┬─────────────────────┬───┘
   │              │                  │                     │
┌──▼─────────┐ ┌──▼──────────────┐ ┌─▼───────────────┐  ┌──▼────────┐
│  core/vault │ │ core/indexer   │ │ agent/*         │  │ config.py │
│  目录树/读写 │ │ 索引抽象接口    │ │ Pydantic AI     │  │ 配置加载   │
│  监听/忽略  │ │ fts5 默认实现   │ │ 工具+会话+HITL  │  │ 环境变量   │
│  markdown  │ │ meili 可选实现  │ │ 编辑安全/备份    │  │           │
└──┬─────────┘ └──┬──────────────┘ └─┬───────────────┘  └───────────┘
   │              │                  │
┌──▼──────────────▼──────────────────▼──────────────────────────┐
│                 宿主机挂载 (Docker volume)                     │
│   /vault ← 你的 Obsidian 库   /data ← 索引库+备份 (持久化)      │
└───────────────────────────────────────────────────────────────┘
```

**分层原则**：`core/` 与 `agent/` 是纯领域逻辑，**不 import 任何 FastAPI 代码**；`api/` 只做 HTTP 适配。这样单测、替换框架、复用核心逻辑都不受影响。

## 2. 模块清单与职责边界

| 模块 | 职责 | 依赖 | 不允许做的事 |
|---|---|---|---|
| `core/vault.py` | 目录树构建、文件读写、忽略规则、watchdog 监听 | 标准库 + watchdog | 不处理 HTTP、不直接操作索引 |
| `core/markdown.py` | 解析 frontmatter / 提取正文与结构 / wikilink 解析 | 标准库 | 不做渲染（渲染归前端） |
| `core/indexer/base.py` | 索引抽象接口（add/remove/rebuild/search） | 标准库 | 不含具体实现 |
| `core/indexer/fts5.py` | SQLite FTS5 + jieba 分词，元数据列（路径/标签/时间） | sqlite3 + jieba | 不越权访问 vault |
| `core/indexer/meili.py` | Meilisearch 实现（可选，需额外容器） | meilisearch 客户端 | 同上 |
| `core/search.py` | 检索编排：query 解析、分页、高亮、命中位置计算 | indexer | 不直接读文件 |
| `core/backup.py` | 快照引擎：硬链接增量快照、定时调度（cron）、保留策略清理、完整性校验、单文件/整库恢复 | 标准库 | 不处理 HTTP；不备份 `data/` 自身 |
| `agent/llm/` | **Pydantic AI 模型配置层**：provider 与模型串映射（DeepSeek/OpenAI/Kimi/Ollama） | pydantic-ai | 不含业务逻辑 |
| `agent/tools/*.py` | Agent 工具：read_file / write_file / search / list_tree（类型化 Python 函数，docstring 自动生成 schema） | core 模块 | 工具不直接调 LLM |
| `agent/loop.py` | Pydantic AI 运行器：会话管理、**工具批准(HITL)**、轮数限制 | llm + tools | 不做文件操作（交工具） |
| `agent/safety.py` | 写前备份、diff 生成、路径白名单校验、禁写目录检查 | core/vault | 不决策内容 |
| `api/routes_*.py` | REST 端点、参数校验、错误映射 | core + agent | 不内联业务逻辑 |
| `frontend/` | 全部 UI 与交互 | 后端 API | 不直连 vault / LLM |

**依赖方向（单向）**：`api → agent → core`、`api → core`，禁止反向。

## 3. 关键数据流

### 3.1 索引构建

```
启动 → core/vault 扫描（忽略规则过滤）→ 逐文件解析（markdown.py 提取正文+元数据）
    → 分批写入 indexer（断点续传，进度上报）→ 完成后启动 watchdog 监听
文件变更事件 → debounce(2s) → 仅重索引变更文件
```

### 3.2 全文检索

```
用户输入 → search.py 解析 query（+可选 path:/tag: 过滤）→ 分词 → 查索引
    → 返回 { 文档路径, 高亮片段, 命中偏移 } → 前端渲染并支持跳转定位
```

### 3.3 Agent 编辑（安全链路）

```
用户指令 → agent 运行器(Pydantic AI) → LLM 决定调用 write_file 工具
    → 框架内置 HITL 批准 + safety.py：① 校验路径在 vault 内且非禁写目录 ② 自动备份到 data/backups/
    → 用户确认 → 执行写入（原子写：临时文件 + rename）→ 返回 diff → 触发索引增量更新
    → 前端展示 diff，用户可撤销（撤销=恢复备份）
```

### 3.4 备份（快照）数据流

```
定时器(cron) / 手动按钮 / 批量操作前 → core/backup.py 创建快照
    → 扫描 vault（跳过 IGNORE_DIRS 与超大文件）→ 硬链接复用上一快照未变文件，仅复制变更文件
    → 写 manifest（文件数/大小/校验抽样）→ 按保留策略清理过期快照
恢复：单文件 → 从目标快照/写前备份复制回 vault（先备份当前版本）
      整库 → ① 强制先建"恢复前快照" ② 双确认 ③ 只读模式异步还原
```

## 4. 技术选型

| 项 | 选择 | 备选 | 理由 |
|---|---|---|---|
| 后端框架 | FastAPI + uvicorn | Flask / Django | 异步、自动 OpenAPI 文档、类型校验（pydantic） |
| 前端 | Vue 3 + Vite | React / Svelte | 中文生态好、模板直观、Vite 构建快 |
| md 渲染 | **remark/rehype + `@quartz-community/obsidian-flavored-markdown`** | markdown-it | Quartz 官方维护的 Obsidian 语法插件包（wikilink/callout/高亮/嵌入全支持），无需自研。详见 docs/09 §3 |
| 全文索引 | **SQLite FTS5 + jieba 预分词（默认）** | Meilisearch | 实战数据：FTS5+jieba 命中率/延迟全面优于 Meili（见 docs/09 §2）；零额外容器；jieba 支持自定义词典。接口抽象保留 meili 逃生通道 |
| LLM 接入 | **Pydantic AI 模型串**（DeepSeek/OpenAI/Kimi/Ollama） | 单一厂商 SDK | 换厂商只改模型串；类型安全；自带校验重试 |
| Agent 框架 | **Pydantic AI（v1.x）** | LangGraph / 自研 | 类型安全、多模型、内置 HITL 与 MCP；同类功能代码量最少。详见 docs/09 §4 |
| 文件监听 | watchdog | inotify（Linux 专属） | 跨平台，容器内 Linux 也适用 |
| 备份 | **快照目录 + 硬链接增量**（`core/backup.py`） | Restic / git 裸仓库 | 零外部依赖、快照即普通目录可人工读取、空间高效；保留策略可配。进阶可插拔 Restic（加密/远程） |
| 配置 | pydantic-settings（读 .env） | 手写 os.environ | 类型安全、默认值、校验 |

> 选型铁律：**优先简单可靠的默认方案**，复杂方案通过抽象接口留作扩展，不为炫技引入重量级依赖。全部选型依据见 [docs/09-技术调研与方案审核.md](09-技术调研与方案审核.md)。

### 4.1 可选集成：Ignis（原版 Obsidian 网页版）

用户若想要「原版编辑体验」（完整插件生态、Graph 视图、命令面板），可并行部署 **Ignis**（真·网页版 Obsidian，Docker 化，`PUID/PGID` 与本项目一致）指向**同一 vault**：

```yaml
# docker-compose.override.yml（可选，不需要就不加）
services:
  ignis:
    image: nobbe/ignis:latest
    environment: [PUID=1000, PGID=1000]
    volumes: [./vaults:/vaults, ./data:/app/data]
```

- 联动方式：Ignis 写文件 → 本项目 watchdog 感知 → 自动增量重索引 → 搜索/Agent 立即可见。
- 取舍：镜像重、首启需网络拉 Obsidian 源码、内存占用高 → **默认不启用**，作为增强项。
- 完整对比见 docs/09 §3。

## 6. 扩展点（怎么加东西不破坏结构）

| 想做的事 | 改哪里 |
|---|---|
| 换/加全文索引引擎 | 实现 `indexer/base.py` 接口，`config.py` 加 `INDEX_BACKEND` 选项 |
| 接新 LLM 厂商 | 改 `agent/llm/` 的模型串映射（OpenAI 兼容即可，大部分零代码） |
| 加 Agent 新能力 | `agent/tools/` 加一个类型化函数（`@agent.tool`），docstring 即工具说明 |
| 加新页面/API | 前端加 view，后端加 `routes_*.py`，按现有模式复制即可 |
| 加忽略目录 | 改 `config.py` 的 `IGNORE_DIRS` 默认值 |

## 7. 路线图（里程碑）

| 阶段 | 交付物 | 验收标准 |
|---|---|---|
| **M0 Docker 骨架** | compose + Dockerfile + config | `docker compose up` 后能打开空壳页面 |
| **M1 Vault 核心** | 目录树 API + 读写 + 监听 | 单测通过；Obsidian 语法文件原样读回 |
| **M2 索引检索** | FTS5 索引 + 搜索 API | 中文关键词命中率测试通过；1 万文件全量索引 < 5 分钟 |
| **M3 API 层** | 四个路由模块 + 异常处理 | pytest e2e 全绿 |
| **M4 前端** | 四视图 + 组件 | 人工走查 3.1/3.2 用户流程顺畅 |
| **M5 Agent** | 工具 + 循环 + 安全 | 「追加待办」「总结文档」场景端到端可用 |
| **M6 收尾** | 测试补全 + CHANGELOG + 镜像验证 | 发布 v0.1.0 |

## 8. 已识别的风险与对策

| 风险 | 对策 |
|---|---|
| Agent 误写破坏笔记 | 写前强制备份 + diff 展示 + 白名单 + 禁写 `.obsidian/` 等目录 |
| 数据错误无法挽回 | **三层防线**：① 写前单文件备份 ② 整库快照（手动/定时，硬链接增量，默认每日）③ 保留策略 + 恢复流程（详见 docs/05 §3.7-3.9）；恢复前强制再快照 |
| 中文检索效果差 | jieba 分词 + FTS5；测试用例覆盖常用中文场景 |
| 大库全量索引慢 | 分批 + 断点续传 + 仅重索引变更文件 |
| Obsidian 语法被编辑器破坏 | 编辑视图纯文本原样保存（渲染与存储分离）；阅读视图渲染用 Quartz 官方 obsidian 语法插件，不手写兼容层 |
| 容器写权限问题 | 非 root 运行 + PUID/PGID 映射 + volume 权限文档说明 |
