# 07 - 更新日志（CHANGELOG）

> 记录每一次版本变更的**更新内容**。格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。
> 每个版本的条目由开发者在发布时从开发日志汇总而来，按「新增 / 修复 / 变更 / 移除 / 文档」分类。

---

## 版本规则

- `x.y.z`：主版本（不兼容 API 变更）· 次版本（向后兼容的新功能）· 补丁（向后兼容的 bug 修复）
- 未发布内容记录在 **Unreleased** 段，发布时移动到具体版本号
- 每次用户可见的变更（功能、修复、配置项）都必须记入

### 已实现（2026-07-31 · M5：AI Agent 集成）✅

**新增**
- `app/agent/llm.py`：pydantic-ai 2.x 模型配置层（内置 provider：deepseek/openai/moonshotai/ollama；api_key 经环境变量注入；`is_configured` 守卫）
- `app/agent/safety.py`：写前安全层（路径白名单/禁写目录/备份/diff 截断）——与框架无关，可独立测试
- `app/agent/service.py`：AgentService（Pydantic AI Agent 构建 + 4 个类型化工具 + SSE 事件队列）+ **PendingStore 暂存式写操作**（HITL：确认前不落盘，30 分钟 TTL 清理）
  - 工具：`read_file` / `search`（中文分词检索）/ `list_tree` / `write_file`（**暂存待确认**，不直接写盘）
- `app/api/routes_agent.py`：POST /chat（SSE：session/text/tool/done/error 事件）、POST /confirm、POST /cancel、GET /session
- 前端 `ChatPanel.vue`：SSE 流式对话 + 写操作确认框（diff 展示 + 确认/取消），App.vue 增加"Agent 对话"标签页
- 测试：test_agent.py（11 用例：safety/pending/工具/守卫）+ test_api.py Agent 4 用例

**验证**
- pytest **98/98 全绿**（累计 M0-M5）
- **M5 端到端冒烟 PASS**（scripts/m5_smoke.py，FunctionModel 模拟 LLM）：工具调用 → SSE tool 事件（含 diff）→ 确认前不落盘 → confirm 写入+索引同步 → cancel 不写入
